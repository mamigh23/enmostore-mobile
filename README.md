# EnmoStore Mobile

Premium mobile commerce application for EnmoStore, targeting Android and iOS.

## Vision

Create a fast, modern, premium, mobile-first shopping experience for EnmoStore that supports real purchases while remaining visually and structurally independent from the existing website.

## Important

This is NOT:

- a WebView wrapper
- a website screenshot
- a 1:1 mobile copy of the website
